## Novità della versione 1.5.0

- Nuovo logo **Torna a Casa** nella barra superiore: richiama la casa e l'orario di rientro, rimane leggibile nei temi Classico, Dim e Smeraldo e riporta sempre alla pagina Oggi.
- Aggiunti i temi **Dim** e **Smeraldo**, memorizzati sul dispositivo e selezionabili dalle Impostazioni.
- README aggiornato con schermate verticali in formato smartphone che mostrano dashboard, tracker, archivio e impostazioni.
- Nuova immagine Docker pubblicata su GitHub Packages e Docker Compose aggiornato per avviarla sulla porta `8080`.
- Pipeline Android aggiornata a Node.js 24; la release allega l'APK firmato con il checksum SHA-256.

### Download Android

Scarica **torna-a-casa-1.5.0.apk** e installalo come aggiornamento della versione precedente. L'APK è una build release firmata.
